各分层用户 活跃 → 被完成任务 转化分析

数据范围：2026-05-11 ~ 2026-05-25（15天汇总） | 任务被完成数据取 05-17 ~ 05-25（9天完整数据）

结论速览

1. 漏斗最大流失点：被打招呼 → 被完成任务

所有分层在「被打招呼 → 被完成任务」这一步的转化率最低。

新高潜用户：被打招呼后只有 57.7% 完成任务；高潜用户：49.0%；新普通用户：54.7%；超30天付费用户：45.0%。

重点瓶颈 主播打招呼了但任务没被完成，说明承接质量或任务门槛有问题。

2. 分发效率两极分化：付费分层"被超额分发"，普通用户几乎不分发

近3天付费 / 新付费 / 30日付费 / 大R：被分发UV > 活跃UV（被多个主播重复分发），分发率 99%~140%。

普通用户：分发率仅 8.0%，被曝光率 11.9%，大量用户根本进不了分发池。

结构性问题 分发资源高度集中在付费分层，普通用户几乎没有被主播触达的机会。

3. 各分层的任务完成结构差异大

大R：收礼任务UV占比最高（41.4%），是唯一以收礼为主导的分层 → 主播对大R的核心动作是"要礼物"。

30日付费 / 近3天付费：上麦任务UV > 私聊UV → 主播引导这些用户上麦停留，上麦是主要承接方式。

新高潜 / 新普通 / 高潜：几乎只有私聊+进房停留，没有收礼任务 → 互动深度浅，以"聊起来、进房"为目标。

业务含义 不同分层的"任务完成"含义完全不同：大R完成=送礼，付费用户完成=上麦，新用户完成=聊天。

一、活跃 → 被完成任务 漏斗

漏斗解读

付费分层（近3天付费、新付费、30日付费、大R）：分发/曝光/打招呼UV都 ≥ 活跃UV，说明这些用户被大量主播重复触达。漏斗的关键瓶颈在「被打招呼→被完成任务」，主播触达了但没把任务做完。

新高潜/新普通：分发→曝光→打招呼每步都有小流失，但最陡的还是最后一步。新高潜的"活跃→被完成任务"总转化率 53.5%，新普通 44.1%。

普通用户：第一步「活跃→被分发」就只剩 8%，绝大部分人没被分发。到被打招呼只剩 33.5%，最后被完成任务的只有 2.9%。

超30天付费用户：分发和曝光都好，但打招呼率骤降到 60.3%，最后被完成任务只有 27.1% → 主播对"已付费但很久了"的用户重视度不够。

二、各分层任务类型 UV/PV 拆解

任务拆解解读

大R用户：收礼任务PV/UV = 1.83，人均完成近2次收礼任务；私聊任务PV/UV = 1.89。主播对大R是"反复触达+追礼"模式。

近3天付费用户：上麦任务PV/UV = 2.11，人均完成2次以上上麦任务 → 主播强引导上麦。私聊PV/UV = 2.70，重复私聊更多。

30日付费用户：上麦任务PV/UV = 2.42，是所有分层中上麦深度最高的，说明30日付费用户上麦停留时间长、主播持续引导。

新高潜/新普通：私聊PV/UV ≈ 1.09~1.10，几乎只聊一次。进房停留PV/UV ≈ 1.05，也是一次性的。互动非常浅。

新付费用户：6类任务都有，是最"全面"的分层。私聊PV/UV=2.80最高，收礼任务PV/UV=1.71，上麦PV/UV=2.06。主播对新付费用户花的心思最多。

注：任务UV为各子任务UV之和（同一用户完成多个子任务会重复计数），PV为实际完成次数。因此UV加总 ≥ 活跃表中的"当日被完成任务UV"（去重值）。
